Compendium is small and moves fast. The newsletter is how you hear about a change
without watching the repo.

One list covers both languages: every issue is sent in English and Spanish, so it
makes no difference which version of the docs you sign up from.

## What you get

- **Release notes.** What shipped in each version, and anything you need to do about it.
- **New tools in the registry.** When a toolchain or a new version lands, so you know it is available to pin.
- **Breaking changes.** Called out ahead of the release, with the migration steps.
- **Occasional guides.** New docs pages worth knowing about.

## How often

There is no set cadence. An issue goes out when there is a release, or when there is
information worth sharing — never to fill a schedule. Busy stretches mean a few emails;
quiet ones mean none.

## Other ways to follow along

If email is not your thing, the same information is public:

- [Releases on GitHub](https://github.com/ileanmjr88/compendium/releases) — the canonical changelog.
- [GitHub Discussions](https://github.com/ileanmjr88/compendium/discussions) — questions and proposals.
- [Roadmap](/roadmap/) — what is planned next.
