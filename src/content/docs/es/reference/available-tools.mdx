Todo lo de abajo viene directamente del registro público. La CLI obtiene el
mismo `index.json` cuando ejecuta `compendium install`. Haga clic en el
nombre de una herramienta para ver todas las versiones en su archivo de
manifiesto.

## Cómo usar una versión específica

Establezca la versión exactamente en su `compendium.toml`:

```toml
[languages]
go = "1.26.1"

[tools]
cmake = "4.3.1"
```

Luego ejecute `compendium install` — el registro resuelve el tarball de
plataforma/arquitectura para su máquina, lo descarga y verifica el checksum
SHA-256.

Si una versión no está listada aquí, no es instalable. Abra un pull request
contra [compendium-registry](https://github.com/ileanmjr88/compendium-registry)
para añadirla.
