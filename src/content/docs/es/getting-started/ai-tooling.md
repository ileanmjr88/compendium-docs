# Para herramientas de IA

Compendium publica documentación legible por máquinas para herramientas de IA.

- **[llms.txt](/llms.txt)** — índice de todas las páginas
- **[llms-small.txt](/llms-small.txt)** — versión condensada para ventanas de contexto más pequeñas
- **[llms-full.txt](/llms-full.txt)** — documentación completa en un solo archivo

Apunte su asistente a la URL que se ajuste a su presupuesto de contexto.
